🔑 إعداد الاتصال بمحرك الذكاء الاصطناعي

تعتمد النسخة الجديدة على واجهة Pollinations Gen ونماذج أحدث. تحتاج إلى مفتاح API خاص بك؛ لا تضع المفتاح داخل الكود أو مستودع GitHub.

يُحفظ المفتاح في ذاكرة الجلسة الحالية فقط، ويُمسح عند إغلاق التبويب. راجع لوحة الخدمة لمعرفة الرصيد والتكلفة والحدود قبل التوليد.
